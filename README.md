# Особистий сайт Олега Нів’євського

Відкрийте `index.html` у браузері. Пункт «Моніторинг» веде на окрему сторінку в `monitoring/`. Англійські версії розміщено в `en/` та `en/monitoring/`. Обидві мови використовують спільний файл `style.css`.

Для GitHub Pages завантажте `index.html`, `style.css`, `.nojekyll` і папки `monitoring/` та `en/` у корінь репозиторію `oniviev/oniviev.github.io`. У Settings → Pages виберіть публікацію з гілки `main` і папки `/ (root)`.

Адреса розділу буде `https://oniviev.github.io/monitoring/`. Сторінки міст і архів оновлюються в окремому репозиторії `oniviev/food-monitoring-network-pages`. Для переходів до випусків там має бути ввімкнено GitHub Pages.

## Як додавати матеріали

- Коротку біографію редагуйте у блоці `id="about"` файлів `index.html` та `en/index.html`.
- Нові публікації додавайте в `id="research"`. Скопіюйте блок `<article class="work">` і замініть назву, посилання та опис.
- Викладання й проєкти редагуйте в блоках `id="teaching"` та `id="projects"`. Українську й англійську сторінки можна оновлювати в одному коміті.
